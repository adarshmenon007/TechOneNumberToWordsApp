# Design Decisions — Number to Words Web Page

Baseline agreed on 2026-11-23, before the build phase. This is the full decision log: every decision, its rationale and
the alternatives rejected. Rows are never deleted — superseded rows keep their original wording with a changed status, and
amended rows keep the original text plus an amendment note. The narrative for reviewers is in the design document; this file
is the detailed record behind it.

## Context
Tech test (Tech_Test_HR.pdf): a web page and server routine that convert numeric input to words
("123.45" → "ONE HUNDRED AND TWENTY-THREE DOLLARS AND FORTY-FIVE CENTS"), passing the words back as a string output.
Deliverables: HTML UI, design-rationale document, test plan, supporting test files (test harnesses with configuration and data,
source, solution/project files, executable if applicable), Readme.md (build/host/use), AI model + conversation history.
Constraints: C#, no third-party libraries or NuGet packages in the solution (test tooling exempt, D4), production quality.
Process: design → agree → TDD (tests first) → code → review, phase by phase. Every decision is made by the author; options
and trade-offs were challenged with AI assistance (see `Docs/AI/`).

| # | Decision | Rationale / rejected alternatives | Status |
